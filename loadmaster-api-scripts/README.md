# Legacy LoadMaster API Scripts

This directory contains the tracked automation scripts imported from the
`LoadMaster-API-Scripts-` repository at commit `14e993102965c33e6772d2cd4021b7bf37021e2d`.

The scripts are retained for reference and lab use. Review configuration values
and test against a non-production LoadMaster before running them. Do not store
credentials, license tokens, private keys, or certificate files in this directory.

The canonical REST API reference and STIG v3.0 technical note are maintained in
`../loadmaster-documents/`; duplicate legacy copies were intentionally excluded.
